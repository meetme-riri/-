# 案件が決まる インフルエンサー営業資料テンプレート

> フォロワー数を並べるだけじゃない。
> 「この人にPRをお願いしたい」と企業に思ってもらう営業資料を、Canvaでかんたん作成。

## コンセプト

「おしゃれな営業資料テンプレ」ではなく、**「インフルエンサーが企業に営業するための営業資料」に特化**した商品。
既存の「りぴさん」24ページ資料（数字→属性→強み→実績の順に情報が並ぶ良い原型）を、
「実績を見せる資料」から**「企業が依頼する理由を作る資料」**へリニューアルする。

## 制作ロードマップ（STEP1〜10）

1. ✅ 企業がインフルエンサーを採用するときに見る情報を確定 → `01-wireframe.md`
2. ✅ 10〜12ページの共通構成を作る → `01-wireframe.md`
3. 女性①を完成（Canva実制作）
4. 女性②を完成（Canva実制作）
5. 女性①の構成をベースに男性①②へ展開 → ルールは `02-design-variations.md`
6. 入力シート・文章テンプレを作る → `03-input-sheet.md` / `04-ai-prompt.md`
7. 「テンプレの使い方」動画を作る
8. 販売ページを作る（`05-product-lineup.md`の価格・構成を反映）
9. モニター10〜20人に使ってもらう
10. 「案件獲得事例」を集めて正式販売 → `06-case-study-format.md`

STEP1・2・6は本ドキュメントで完了。STEP3以降はこの設計図をもとにCanvaでの実制作に進める。
