# 案件獲得事例 収集フォーマット

購入者からの報告を「導入事例」として蓄積し、販売ページに掲載していく。10〜20件溜まると訴求力が大きく上がる。

## 購入者への依頼テンプレート（DM・メール文面）

```
テンプレートをご購入いただきありがとうございます！
差し支えなければ、営業結果を教えていただけると嬉しいです（匿名掲載も可能です）。

・このテンプレを使って何社くらいに営業しましたか？
・返信は何社からありましたか？
・案件は決まりましたか？（差し支えなければジャンルだけでも）
```

## 事例フォーマット（掲載用）

```
【使用前】
「【 例：営業資料を作るのが苦手だった／実績を数字でしか見せられなかった 】」

【使用後】
「【 例：◯社に営業 → 3社から返信 → 1社案件決定 】」

使用デザイン：【女性①/女性②/男性①/男性②】
ジャンル：【 】
匿名希望：【 有 / 無 】
```

## 運用ルール

- 匿名希望の場合はアカウント名・企業名を伏せ、ジャンルと結果の数字のみ掲載
- 事例は月1回程度まとめて集計し、販売ページの「導入事例」セクションを更新
- 良い事例が集まったら、そのジャンル向けの訴求コピーを販売ページに追加していく（例：「暮らし系インフルエンサーの事例が多数」など）
