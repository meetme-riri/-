# 営業資料文章作成プロンプト

`03-input-sheet.md` を埋めた後、その内容を以下のプロンプトに貼り付けて使う。
生成した文章を `01-wireframe.md` の各ページ（特に02・05・07-08）に流し込む。

---

## プロンプト本文

```
以下の情報をもとに、企業向けインフルエンサー営業資料の文章を作成してください。

【発信ジャンル】
【フォロワー数】
【フォロワー属性】
【過去実績】
【得意なPR】
【発信コンセプト】

企業担当者が「このインフルエンサーに依頼したい」と思えるように、
広告感を出さず、信頼感のある文章にしてください。

出力は以下の5つに分けてください：
1. ABOUT ME（人柄・世界観を伝える3〜4行の自己紹介文）
2. フォロワー属性から企業商品との相性を伝える1文
3. MY STRENGTH（PRで何ができる人かを表す1〜2行のコピー）
4. PR CASE STUDY用の「工夫したポイント」1〜2行（実績ごとに作成）
5. CONTACT用の一言メッセージ（1行）
```

---

## 使い方メモ

- 【 】には `03-input-sheet.md` の該当項目をそのまま貼る
- 生成された文章はそのままCanvaに流し込んでよいが、本人の口調に合わせて一人称・語尾を微調整すること
- ケーススタディが複数ある場合は「4」を実績ごとに繰り返し生成する
