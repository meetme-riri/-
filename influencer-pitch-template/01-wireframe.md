# 販売用12ページ・ワイヤーフレーム(女性①暮らし系ベース)

企業が3分で「この人に頼みたい」と判断できることを目標にした構成。
`【 】`は差し替え箇所。Canva上では `🟡 YOUR ACCOUNT NAME` のような黄色マーカー付きの指示テキストとして配置する。

---

## 01｜表紙 COVER

**レイアウト**：プロフィール写真（大）＋アカウント名＋コンセプトコピー＋種別ロゴ（Instagram/TikTok等）

```
【アカウント名】 Instagram PR MEDIA KIT
「暮らしをもっと【キーワード】に」
```

- 差し替え：プロフィール写真、アカウント名、コンセプトコピー1行

---

## 02｜ABOUT ME（私は何者なのか）

人柄・世界観を伝えるページ。数字は出さない。

```
発信テーマ：【例：暮らし/収納/インテリア】
活動内容：【例：整理収納アドバイザーとして◯年活動】
発信歴：【◯年◯月〜】
居住地：【※必要な人だけ】
家族構成：【※必要な人だけ】
得意ジャンル：【例：狭い部屋の収納/時短家事】
```

一言コピー例：
> 「忙しい毎日の中でも、心地よい暮らしを諦めない」をテーマに発信しています。

---

## 03｜ACCOUNT DATA（数字）

```
Instagramフォロワー：【 】人
TikTokフォロワー：【 】人
YouTube登録者：【 】人
総フォロワー：【 】人
月間リーチ：【 】人
平均再生数：【 】回
平均保存数：【 】件
```

- レイアウト：大きい数字を横並び3〜4個。グラフや棒表示があると信頼感が上がる。
- **フォロワー数推移（成長グラフ）を入れられる場合は入れる**：折れ線・棒グラフで「今も伸びている／急増中」を見せると、
  静止した数字だけより信頼感が上がる（例：「◯ヶ月で◯万人増加」「運用開始から◯年、現在も増加中」）。伸びが小さい・停滞期の場合は省略可。

---

## 04｜FOLLOWER INSIGHT（フォロワー属性）

```
男女比：女性【 】% / 男性【 】%
年齢層：【 】代がメイン（【 】%）
地域：【上位3地域】
興味関心：【例：暮らし、育児、コスメ】
```

**必須の一文（企業が最も知りたい結論）**：
> この属性データから、【御社の商品カテゴリ】と相性の良い層にリーチできます。

- 複数媒体で活動している場合は、Instagram／TikTok／YouTubeそれぞれの視聴者層を分けて見せると精度が上がる（媒体ごとに年齢層・男女比が異なることが多いため）。

---

## 05｜MY STRENGTH（企業PRで何ができる人か）

単純な実績数値ではなく「PRの得意技」を言語化する。

```
私は、
「【 得意な見せ方 】」ことが得意です。

例：
商品を日常生活に自然に取り入れ、
「広告感を抑えながら商品の魅力を伝える」ことが得意です。
```

- 箇条書きで2〜3個の強みを添えてもよい（例：丁寧な言葉選び／写真の世界観統一／ストーリーズでの高い反応率）
- **強みは可能な限り数字で裏付ける**。定性的な一言だけより、具体的な数字が付くと説得力が跳ね上がる。

```
例：
コンテンツ制作力：【 】万〜【 】万再生のバズ動画【 】本以上
拡散・反響力：【 】時間で【 】件以上の視聴者からの反響
継続的な話題化：【 】日間で合計【 】万回再生
```

---

## 06｜CREATIVE STYLE（どんなPR動画を作れるか）

画像を大きく使い、4分類で提示。企業が「うちの商品ならこの見せ方できそう」とイメージできるページ。

```
Lifestyle｜暮らしに取り入れる自然な使用シーン
Review｜使用感・ビフォーアフターを丁寧に紹介
How to｜使い方・活用方法を分かりやすく解説
Vlog｜1日の暮らしの中で商品を自然に登場させる
```

各カテゴリに実際の投稿サムネイル（3〜4枚）を差し替え配置。

---

## 07〜08｜PR CASE STUDY（実績のケーススタディ化）

実績一覧ではなく「1社=1ページの成功事例」として見せる。1〜2社分をこの2ページで展開。

```
【企業名】様
【メイン数値：例 227万再生】

再生数：【 】
保存数：【 】
コメント数：【 】
CTR：【 】
売上／購入数：【 】
検索数の変化：【 】

工夫したポイント：
「【 】」
```

工夫ポイントは1〜2行で言い切る。数字の並びより、この一言が企業の意思決定を左右する。

---

## 09｜PR WORKS（過去PR実績一覧）

```
これまでのPR実績：【 】社以上
```

企業ロゴ・商品画像をグリッドで並べる（6〜12個）。ロゴがない場合はジャンルアイコン＋商品名でも可。

---

## 10｜AVAILABLE PR（対応可能なPRメニュー）

```
□ Instagramリール
□ フィード投稿
□ ストーリーズ
□ TikTok
□ YouTube Shorts
□ UGC制作
□ 二次利用（広告活用）可
□ 広告運用素材の提供
□ 撮影のみ対応
```

対応可・不可、または個別見積りをチェックマーク／◯✕で明示。

---

## 11｜PR FLOW（依頼から投稿までの流れ）

```
お問い合わせ
　↓
ヒアリング
　↓
企画提案
　↓
撮影
　↓
投稿
　↓
レポート
```

矢印を使ったシンプルな縦フロー図。「ちゃんとしている」印象を与える役割。

## ページ数を増減する場合の優先順位

- 削れるなら削る候補：09｜PR WORKS（実績が少ないうちは06に統合可）
- 絶対に外せないページ：03（数字）／04（属性）／05（強み）／07-08（ケーススタディ）
  → ここが「案件が決まる」ための核。他ページより優先して文章を練る。

## 任意追加ページ（該当者のみ）

- **行政・自治体PR実績**：企業PRとは別枠で見せると効果的（発注元・案件名・イベント参加実績など）。
  行政案件の実績がある人向けのオプションページとして、07-08と09の間に追加できるようにしておく。
