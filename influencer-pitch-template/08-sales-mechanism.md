# 販売できる仕組み全体設計

`01〜07` で「商品の中身」は設計済み。ここでは「それをどう作り、どう届け、どう売るか」を決める。

## 全体の流れ

```
① 商品を作る（デザイン4種＋テキスト一式）　→ 済（01・02）
② 購入者に届ける形にする（配布方法）
③ 売る場所を決める（販売プラットフォーム）
④ 買ってもらう導線を作る（販売ページ・集客）
⑤ 使ってもらい実績化する　→ 済（06）
```

---

## ② 配布方法：Canvaテンプレートリンク方式

個人が売るCanvaテンプレ商品は、ほぼ全て以下の方式で配布されている。

1. 完成した4デザインそれぞれを **Canvaの「テンプレートとして共有」リンク** で発行する
   （このリンクを開くと、購入者のCanvaアカウントに"コピー"が作られる。編集しても元データは壊れない）
2. 購入者には以下をまとめて渡す：
   - 4デザインぶんのテンプレートリンク（`02-design-variations.md`の4種）
   - `03-input-sheet.md`（入力シート）
   - `04-ai-prompt.md`（AIプロンプト）
   - 使い方ガイド（PDF or 動画）
3. 配布物はPDFかZIPにまとめ、購入プラットフォームのダウンロード機能で渡す（Canvaリンクはテキストで記載）

**注意点**：
- 使用する画像・フォントがCanva Pro限定の場合、購入者がCanva Pro未加入だと使えない → 制作時は無料プランでも使える素材を優先する
- Canvaの規約上、テンプレートを「販売」すること自体は個人クリエイターに許可されている（Canva公式もテンプレート販売を想定した機能を用意している）

## ③ 販売プラットフォームの選択

以下のいずれかがこの商品に向いている。決めるのはビジネス判断なので、方向性を教えてほしい。

| プラットフォーム | 特徴 |
|---|---|
| **BASE / STORES** | デジタルダウンロード販売に対応。決済・特典動画・複数商品(STARTER/STANDARD/PRO)の管理がしやすい |
| **note** | 文章込みで販売しやすい。「なぜこの資料が必要か」を記事化して同時に売れる。デジタル商品の直接販売機能あり |
| **ココナラ** | 「営業ノウハウ動画・添削1回」付きのPROプランのような、サービス要素が強い商品と相性が良い |

STANDARDをメイン商品として売るなら BASE/STORES、
「なぜ必要か」を丁寧に伝えて信頼を積みたいなら note との併用がおすすめ。

## ④ 販売ページ・集客導線

`05-product-lineup.md`の訴求順（①違いを示す→②デザイン比較→③4要素を提示→④事例→⑤価格表）をそのままLPの章立てにする。

**集客の初動（STEP9のモニター施策と連動）**：
1. 自分のInstagram/TikTokで「営業資料を作る大変さ」に共感を集める投稿をする
2. 無料モニター10〜20人に配布し、`06-case-study-format.md`で事例を回収
3. 事例が集まった時点でLPを公開し、正式販売を開始する

## 決めてほしいこと（ビジネス判断）

1. 販売プラットフォームはどれにするか（BASE / STORES / note / その他）
2. Canva Pro限定の素材を使うかどうか（購入者側の負担になるため）
3. モニター募集は誰に声をかけるか（既存フォロワーの中のインフルエンサー仲間など）

これが決まれば、STEP3（女性①のCanva実制作）に進める。
